# Wednesday, July 15th

## Setting Up GitHub SSH

- Connect to GitHub with SSH, https://docs.github.com/en/free-pro-team@latest/authentication/connecting-to-github-with-ssh

1. Generate a new SSH key.

  ```bash
  ssh-keygen -t ed25519 -C [YOUR_EMAIL@EXAMPLE.COM] -f [PATH_TO_KEY_FILE]
  ```

2. Add your SSH key to the ssh-agent

  ```bash
  eval "$(ssh-agent -s)" # Get the agent pid

  ssh-add [PATH_TO_YOUR_PRIVATE_KEY_FILE] # Use "chmod 400" to secure the file from other users.

  ```

3. Copy the Generated Public Key to GitHub

  ```bash
  cat [PATH_TO_YOUR_PUBLIC_KEY_FILE] # Copy this to your GitHub SSH field.
  ```

4. Verify SSH Connections to GitHub

  ```bash
  ssh -T git@github.com # Attempts to SSH to GitHub

  # Check GitHub's public key fingerprints from verified sources, for example https://docs.github.com/en/authentication/connecting-to-github-with-ssh/testing-your-ssh-connection
  ```

## Notes on Setting up Git

### Basic Information

```bash
git config --global user.name [YOUR_NAME]
git config --global user.emal [YOUR_EMAIL]
git config --global core.editor [YOUR_CODE_EDITOR]
```

### Signing Commits

https://git-scm.com/book/en/v2/Git-Tools-Signing-Your-Work

```bash
git config --global commit.gpgsign true
git commit -S -m [YOUR_MESSAGE]
git log --show-signature # verifing commits
```

## Running Local LLMs on Windows with NVIDIA

### References

1. _How to run Local LLMs on Windows with NVIDIA (llama.cpp + CUDA)_, https://help.visokio.com/support/solutions/articles/42000115649-how-to-run-local-llms-on-windows-with-nvidia-llama-cpp-cuda-
2. _How to Run Qwen 3.5 Locally on a Single GPU: Step-by-Step Guide_, https://www.datacamp.com/tutorial/run-qwen-3-5-locally

### 1. Hardware Check

Double check the size of model parameters and the dedicated graphic memory on your machine. For example, "you cannot run 32B models fully on GPU with 8GB VRAM. They will spill into RAM and performance will suffer. The sweet spot is 14B models." (1)
