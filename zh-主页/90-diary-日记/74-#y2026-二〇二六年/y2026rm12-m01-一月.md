# 礼拜五, 一月三十日

这几天我一直想要不要调整一下小书的结构, 把之前的在文件名里挤下排序, 网页"类型", URL段, 和菜单标题的设计改掉. 我复制了一个新的repo, 然后尝试在每个Directory加一个csv文件去表示这类信息. 我在修改的过程中感觉到之前那样做其实还挺好的. 小标题的设计避免了两种语言"同样"的URL地址也有一样的文件名的问题, 同时它们也方便我在编写的过程中去阅读. 只是我之前的用分号去实现这一点确实看起来有些奇怪. 我发现改成我现在的用"-"去分割文件名中不同含义的内容的文件命名习惯也能挺好看. 或许我明天应该改成那样.

# 礼拜六, 一月二十四日

我尝试了用Stew Meat去做Mongolian Beef, 似乎肉块还是有些厚. 我发现熟的过程有点慢, 所以在锅里的时候我拿剪刀剪了剪.

# 礼拜三, 一月二十一日

下午, 我开始准备用铸铁锅去煎牛排, 用ChefIq锅去做蘑菇酱. 这一次我买的是完整的Baby Bella蘑菇, 切蘑菇也算是个有趣的问题. 我感觉很难有办法能把这种形状的物体切成一样的形状. 虽然我看之前的切好的蘑菇大概就是一直竖着切的, 但是我还是试了试"分治", 一直从中心平分. 我感觉效果也还不错.

我大概测试了一下铸铁锅温度升高的规律, 大概找到了一个和菜谱上五分钟把锅表面温度升高到210摄氏度的火力. 我用这个火力煎出的牛排和用ChefIq锅煎出的差不多. 我很感恩.

# 礼拜二, 一月二十日

今天是新学期的第一天. 我在上课的时候想到之前经常想起的: "记录其实是为了遗忘."

晚上的时候我在路上捡到一个似乎是面包样式的钥匙扣, 我就捡了回来然后发了一条Reddit的帖子.

晚间, 我准备第二次尝试做Dojin Mustard牛排. 这次, 我打算使用足够多的蘑菇以及shallot洋葱. 第一次我做的Dojin牛排虽然也比较成功, 但是我感觉酱料稍微有点苦. 我想大概是蘑菇的数量不太够然后有点糊了的缘故吧. 我想可能还有我提前倒好了Heavy Cream导致水分蒸发然后特别稠的缘故. 这次, 做好的酱料相较第一次确实更白了. 我也调整了摆盘的策略. 这一次我在倒完酱料之后把牛排放进盘子里. 我感觉拍照的效果好了很多. 我很感恩.
